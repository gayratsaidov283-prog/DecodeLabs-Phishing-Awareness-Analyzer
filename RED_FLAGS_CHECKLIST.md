# Phishing Red Flags Checklist

Decode Labs Cyber Security Internship — Project 3

## 1. Sender Red Flags

- Unknown or unexpected sender
- Sender name does not match the email domain
- Look-alike or misspelled domain
- Message impersonates a trusted organization

## 2. Message Red Flags

- Urgent requests
- Threats of account suspension
- Requests for passwords or credentials
- Requests to verify an account
- Unexpected payment requests
- Prize or reward messages
- Pressure to act immediately

## 3. URL Red Flags

- Suspicious domain extensions
- Misspelled domains
- Unusually long domains
- Excessive hyphens
- URLs containing an @ symbol
- Link text does not match the real destination

## 4. Attachment Red Flags

Be cautious with unexpected files such as:

- .exe
- .js
- .vbs
- .scr
- .zip
- Macro-enabled Office documents

## 5. Response Procedure

If a message appears suspicious:

1. PAUSE — Do not click links or open attachments.
2. VERIFY — Confirm the request using a trusted communication channel.
3. REPORT — Report the suspicious message to the appropriate security team.

## Triage

SAFE → CLOSE

SUSPICIOUS → WARN USER

MALICIOUS → BLOCK & ESCALATE
